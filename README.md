This repository contains the simulation engine, configuration matrices, and results database for the paper: **"Game-Theoretic Industrial Control Systems Defense using Cyber Kill Chain Model and MITRE ATT&CK."**

## Project Overview
This project models cybersecurity in Industrial Control Systems (ICS) and Predictive Maintenance (PdM) environments as a strategic interaction between an adaptive adversary and a defender. Moving beyond static checklists, the simulation maps the **Cyber Kill Chain (CKC)** to specific **MITRE ATT&CK for ICS** techniques. 

The engine uses **Mixed-Strategy Nash Equilibrium (MSNE)** and Bayesian learning to evaluate three defensive taxonomies:
1. **Static Defense:** Fixed, predictable security policies (Baseline).
2. **Hardened Defense:** High-detection security that risks operational downtime and alert fatigue.
3. **Adaptive (Dynamic) Defense:** A reactive strategy that creates a "Choke Point" at the Exploitation stage.

The findings demonstrate that dynamic strategies optimize the **Total Cost of Defense (TCD)**, maximize system resilience, and align with the human-centric goals of Industry 5.0 by reducing operator alert fatigue.

## Repository Structure

* `/configs` — Contains the JSON configuration files that drive the simulation's logic.
  * `payoff_model.json`: Defines utilities, detection penalties, and Monetary Unit (MU) costs.
  * `attack_techniques.json`: The MITRE ATT&CK for ICS mappings and base probabilities.
  * `config_phase2.json`: Experiment definitions (Baseline, Insider Threat, Hardened).
* `/data` — Contains the generated SQLite database (`phase2.db`) used for analysis.
* `/src` — The Python simulation engine broken down by execution phase.
* `/figures` — High-DPI outputs generated by the visualization script.

## Reproducibility: How to Run the Simulation

The simulation is broken into distinct sequential phases to separate the baseline generation, mathematical solving, and visualization.

### 1. Installation & Setup
Ensure you have Python 3.9+ installed. Create a virtual environment and install the required dependencies:

```bash
python3 -m venv .venv
source .venv/bin/activate  # On Windows use: .venv\Scripts\activate
pip install -r requirements.txt
2. Execution Pipeline

Run the source scripts in the following order from the root directory:

Phase 2: Baseline Generation

Bash
python src/sim_phase2.py
Runs the "Baseline Rational" simulation against a Static Defender and exports raw .csv files.

Phase 3: Database Initialization

Bash
python src/sim_phase3.py
Initializes phase2.db and imports the Phase 2 baseline data to establish the SQLite schema.

Phase 4: Advanced Game-Theoretic Solver

Bash
python src/sim_phase4.py
The core engine. Solves the 3x3 MSNE matrices, implements Bayesian belief updating for the attacker, and executes the Adaptive, Hardened, and Insider Threat scenarios. Syncs all outcomes to phase2.db.

Phase 5: Academic Visualization

Bash
python src/sim_phase5.py
Parses phase2.db and generates the IEEE/Academic formatted high-DPI .png figures found in the paper (Attacker Survival Rate, Cost-Resilience Trade-Off, Signal-to-Noise).

🔬 Modifying the Experiment
Reviewers and researchers are encouraged to modify the simulation parameters to test alternative hypotheses.

To adjust the cost of defense (MU) or attacker utility, edit configs/payoff_model.json.

To adjust the base success/detection probabilities of specific industrial attacks, edit configs/attack_techniques.json.
